# Categoría: Efectos_visuales

Esta sección recopila todos los efectos pertenecientes a **efectos_visuales** registrados en ZenCore.

---

## `set_glowing`

Hace que la entidad objetivo brille con efecto de contorno resplandeciente.

## Ejemplo de Configuración

```yaml
effects:
  - type: SET_GLOWING
    glowing: true
```

---

## `shoot_firework`

Lanza un cohete de fuegos artificiales decorativo en la ubicación.

## Ejemplo de Configuración

```yaml
effects:
  - type: SHOOT_FIREWORK
    power: 1
```
