# Categoría: Mensajes_ui

Esta sección recopila todos los efectos pertenecientes a **mensajes_ui** registrados en ZenCore.

---

## `send_message`

Alias de MESSAGE para enviar mensajes con MiniMessage.

## Ejemplo de Configuración

```yaml
effects:
  - type: SEND_MESSAGE
    message: '<green>¡Efecto activado!</green>'
```
