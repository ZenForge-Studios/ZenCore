# `lightning`

- **Categoría:** mundo_y_bloques

- **Identificador / Alias:** `LIGHTNING`
- **Descripción:** Invoca un relámpago en la ubicación del objetivo o bloque.

### Ejemplo de Configuración
```yaml
effects:
 - type: LIGHTNING
    target: TARGET
    strike: true # Si es true, inflige daño de rayo
```
