# `launch_projectile`

- **Categoría:** entidades_y_proyectiles

- **Identificador / Alias:** `LAUNCH_PROJECTILE`
- **Descripción:** Dispara un proyectil (`SNOWBALL`, `FIREBALL`) desde el jugador.

### Ejemplo de Configuración
```yaml
effects:
 - type: LAUNCH_PROJECTILE
    type: FIREBALL
    speed: 1.8
```
