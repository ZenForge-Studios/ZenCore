# `condense_items`

- **Categoría:** `inventario`
- **Identificador / Alias:** `CONDENSE_ITEMS`

---

Compacta ítems y minerales sueltos en bloques dentro del inventario del jugador.

## Ejemplo de Configuración

```yaml
effects:
  - type: CONDENSE_ITEMS
    materials:
      - IRON_INGOT
      - GOLD_INGOT
```
