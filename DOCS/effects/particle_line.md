# `particle_line`

- **Categoría:** efectos_visuales_y_rayos_cinemticos

- **Identificador / Alias:** `PARTICLE_LINE`
- **Descripción:** Traza una línea geométrica de partículas desde los ojos del jugador hacia el objetivo.

### Ejemplo de Configuración
```yaml
effects:
 - type: PARTICLE_LINE
    particle: ENCHANT
```
