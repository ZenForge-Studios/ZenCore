# `gravity_well`

- **Categoría:** nuevos_efectos_de_entidad_auras_y_utilidad

- **Identificador / Alias:** `GRAVITY_WELL`
- **Descripción:** Genera un pozo de gravedad que succiona a todas las entidades hacia el centro.

### Ejemplo de Configuración
```yaml
effects:
 - type: GRAVITY_WELL
    radius: 7.0
```
