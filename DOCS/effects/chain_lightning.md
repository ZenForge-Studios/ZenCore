# `chain_lightning`

- **Categoría:** `combate`
- **Identificador / Alias:** `CHAIN_LIGHTNING`

---

Dispara un rayo que encadena e impacta a múltiples entidades vivas consecutivas.

## Ejemplo de Configuración

```yaml
effects:
  - type: CHAIN_LIGHTNING
    chains: 3
    radius: 5.0
    damage: 4.0
```
