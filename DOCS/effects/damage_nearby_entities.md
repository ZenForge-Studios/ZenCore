# `damage_nearby_entities`

- **Categoría:** `combate`
- **Identificador / Alias:** `DAMAGE_NEARBY_ENTITIES`

---

Inflige daño a todas las criaturas hostiles o jugadores en un radio determinado.

## Ejemplo de Configuración

```yaml
effects:
  - type: DAMAGE_NEARBY_ENTITIES
    radius: 4.0
    damage: 4.0
```
