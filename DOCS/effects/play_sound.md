# `play_sound`

- **Categoría:** sonidos

- **Identificador / Alias:** `PLAY_SOUND / SOUND`
- **Descripción:** Reproduce un sonido de Minecraft con volumen y tono ajustables.

### Ejemplo de Configuración
```yaml
effects:
 - type: PLAY_SOUND
    sound: ENTITY_WITHER_SPAWN
    volume: 1.0
    pitch: 1.2
```
