# `tree_feller`

- **Categoría:** nuevos_efectos_de_minera_agricultura_y_entorno

- **Identificador / Alias:** `TREE_FELLER`
- **Descripción:** Tala el árbol completo de un solo golpe recorriendo los troncos conectados.

### Ejemplo de Configuración
```yaml
effects:
 - type: TREE_FELLER
    max_blocks: 128
```
