# `cancel_event`

- **Categoría:** estado_del_tem

- **Identificador / Alias:** `CANCEL_EVENT`
- **Descripción:** Cancela el evento nativo de Bukkit que originó el trigger (previene el daño, la rotura del bloque o el clic).

### Ejemplo de Configuración
```yaml
effects:
 - type: CANCEL_EVENT
```
